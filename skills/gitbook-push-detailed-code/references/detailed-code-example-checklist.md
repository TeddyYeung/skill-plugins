# Detailed Code Example Checklist

Use this checklist before final output.

## 1) Completeness
- Show full imports.
- Show full class/function signatures.
- Show wiring code (dependency injection, route registration, startup).
- Show file path per snippet.

## 2) Environment
- Specify language/runtime version.
- Specify package versions.
- Specify required environment variables and sample values.
- Include install/build command.

## 3) Concrete Inputs/Outputs
- Provide sample input payloads.
- Provide expected output payloads.
- Provide expected logs or console output.
- Provide one invalid input and expected error output.

## 4) Error and Edge Handling
- Include timeout and retry logic if network is involved.
- Include null/empty data handling.
- Include exception mapping and user-facing error messages.

## 5) Verification
- Include test command.
- Include at least one unit test example with explicit assertion.
- Include at least one integration/E2E check command when applicable.

## 6) Readability
- Prefer runnable snippets over pseudo-code.
- Limit abstraction in first example; show realistic values.
- Add short comments only where the logic is non-obvious.
