# GitBook Report Template (Korean)

## Header
- 제목
- 원문 링크
- 발행일
- 대상 독자
- 핵심 질문 (So what?)

## Question
- 문서가 답하는 핵심 질문 1문장

## Answer
- 한 줄 결론
- 근거 3개

## Executive Summary
- 핵심 인사이트 3-5개
- 비즈니스 임팩트 (비용/리스크/속도/품질)
