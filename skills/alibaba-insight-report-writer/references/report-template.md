# McKinsey-Style Tech Insight Report Template (KR)

## 0. Header
- 제목
- 원문 제목 / 링크 / 발행일
- 대상 독자 (경영진, PO/PM, 개발팀)
- 핵심 질문 (So what?)

## 1. Question / Answer (Repository Rule)
## Question
- 이 문서가 답하는 핵심 질문 1문장

## Answer
- 한 줄 결론
- 결론을 지지하는 핵심 근거 3개

## 2. Executive Summary (1 page)
- 한 줄 결론
- 핵심 인사이트 3-5개
- 비즈니스 임팩트 요약 (예: 비용, 리스크, 개발생산성, 고객경험)

## 3. 문제 정의·배경
- 원문의 문제와 맥락
- 왜 지금 중요한지
- 어떤 상황에서 유효한지

## 4. 핵심 개념 설명
- 비개발자도 이해 가능한 개념 설명
- 예시/비유 포함
- Glossary (영문 병기)

## 5. 상세 내용 (아키텍처/프로세스)
- 원문 논리를 재배열해 설명
- 필수 시각화:
  - 아키텍처 다이어그램
  - 시퀀스/플로우
  - 비교 표 (기존 vs 제안)
- 각 도식 하단에 한 줄 메시지 캡션

## 6. 인사이트·시사점
- 조직/제품/프로세스 적용 포인트
- 기대 효과 (KPI, 비용, 리스크, 생산성)
- 한계와 주의사항

## 7. Action Plan (Now / Next / Later)
1. Now (0-2주)
2. Next (3-6주)
3. Later (7주+)

## 8. 리스크와 대응
| 리스크 | 조기 신호 | 대응책 |
| --- | --- | --- |
| 예시 | 예시 | 예시 |

## 9. Q&A
- 독자가 헷갈릴 질문 3-5개
- 질문마다 짧은 답변

## 10. Quiz
- OX/단답형 3-5문항
- 정답 + 해설

## 11. 부록
- 원문 링크
- 추가 참고자료
- 근거/출처 매핑
  - 사실: source-backed statement
  - 해석: author inference
